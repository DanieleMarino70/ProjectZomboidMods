# 🧟 Project Zomboid — Mod Collection

> **A collection of custom mods for Project Zomboid (Build 42).**  
> *Una collezione di mod personalizzati per Project Zomboid (Build 42).*

---

## 🇬🇧 English

### 📖 Description

This repository contains a collection of mods for Project Zomboid Build 42, each one adding new traits, mechanics and gameplay features to enrich the survival experience.  
Every folder in this repository corresponds to a standalone mod that can be installed independently.

### 🛠️ Installation (Manual)

1. Download or clone this repository
2. Copy the mod folder(s) you want into:
   ```
   C:\Users\<YourUsername>\Zomboid\mods\
   ```
3. Launch Project Zomboid
4. Enable the mod(s) from the **Mods** menu before starting a game

### 🎮 Compatibility

- ✅ Project Zomboid **Build 42+**
- ✅ Each mod can be used independently or combined with others
- ⚠️ Always check individual mod folders for specific compatibility notes
